Overview

Noise Fest needed a visual language that could match the volume of the event itself — loud, layered, and unmistakable. The project pairs brand-level art direction with AI-generated film to deliver a campaign that lives across print, social, and motion.

The Brief

What the work had to say

A live music event with a heavy underground identity. The campaign had to feel like the room before the first set drops — tense, saturated, slightly broken. It needed to read as a festival, not a poster series: one tone, multiple surfaces, no filler.

Tools & Decisions

Why this stack

  • Midjourney — for grain, atmosphere, and character. Faster than a photoshoot for testing a dozen visual directions in an afternoon.
  • Grok — for prompt iteration and copy. Used as a sparring partner to pressure-test taglines and prompt structure before generation.
  • Kling — for motion. Kling held style continuity across short shots better than the alternatives I tested for this aesthetic.
Process

From prompt to cut

  1. 01

    Prompt structure

    Locked a base prompt template — subject, lens, lighting, grain, palette — so every image read as the same world.

  2. 02

    Image generation

    Generated wide in Midjourney, narrowed to a tight set of frames that defined the campaign's visual rules.

  3. 03

    Video

    Animated the selected stills through Kling, keeping motion minimal — drift, flicker, smoke — so the stills stayed the hero.

  4. 04

    Edit

    Cut to a single track in After Effects. Added grain, type, and a low-end pass so the spot felt physical, not rendered.

What I'd do differently

I'd build the motion language earlier — a few of the strongest stills didn't translate to video, and I'd rather discover that in week one than week three. Next time, prompt-test for motion first, then design the stills around what moves.
